# Infinity Premium Villas — rebuild

A fast, modern rebuild of a luxury villa rental site: five static pages
(Home, Villas, Gallery, Book Now, Contact), built with [Vite](https://vitejs.dev)
and no framework — plain HTML/CSS/JS for the smallest possible payload.

## Why this repo, and why placeholder content

This started as a request to rebuild infinitypremiumvillas.gr. That site is
behind CAPTCHA/anti-bot protection, so its real photos, videos, and copy
were not scraped — bypassing a site's bot protection isn't something to
automate. Instead this rebuild uses real, freely-licensed stock photography
(credited in `.imgsrc/CREDITS.md`) and placeholder copy, matching the
original's structure and sections, as a pitch/demo build. Swap in the
client's actual photography and text before launch.

Also: the GitHub integration available in this session couldn't create a
new repository, so this lives in the `Hatzinikolaou-Winery` repo despite
the name mismatch — rename the repo on GitHub whenever convenient.

## What's here

- **Home** — hero, intro, feature highlights, featured villas, video, testimonial, CTA
- **Villas** — full detail for all 3 villas (amenities, pricing, imagery)
- **Gallery** — filterable photo grid with a lightbox, plus a video showcase (click-to-load YouTube embeds — nothing loads until clicked)
- **Book Now** — a reservation UI (villa/dates/guests, live price summary) — this is a front-end mockup only; submitting shows a confirmation but does not send anywhere or take payment
- **Contact** — contact details, a form (mock, no backend), and an embedded map

## Performance choices

- No JS framework/runtime shipped — one small vanilla JS file (~2.4kB gzipped)
- Every photo is served as WebP with JPEG fallback, at multiple widths (`<picture>`/`srcset`), generated by `.imgsrc/optimize.mjs`
- LCP hero image is preloaded; below-fold images are `loading="lazy"`
- Videos are never embedded eagerly — a poster image + click-to-load facade avoids pulling in YouTube's JS/iframe cost until a visitor actually wants to watch
- Fonts load via a real `<link rel=stylesheet>` (not a render-blocking `@import`), with `preconnect`

## Development

```bash
npm install
npm run dev       # local dev server
npm run build     # production build to dist/
npm run preview   # preview the production build
```

To reprocess source photography after swapping files in `.imgsrc/`:

```bash
node .imgsrc/optimize.mjs
```
